📖 About the Website

The Real Number Classifier is an educational website designed to help students understand the different classifications of real numbers.

The website allows users to enter a number and automatically determine whether the number belongs to the natural, whole, integer, rational, irrational, and real number sets.

This project combines mathematics with web development using HTML, CSS, and JavaScript. It provides a simple, interactive, and user-friendly way of learning about the real number system.

⚙️ How It Works

Follow these simple steps to classify a number:

Step 1: Enter a number in the input box.
Step 2: Click the Classify button.
Step 3: The system analyzes the number and checks which number sets it belongs to.
Step 4: The results will appear as YES or NO.
Step 5: Read the explanation below the results to understand the classification.
